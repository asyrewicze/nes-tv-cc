# pixel-tv

A Claude Code plugin (mod): an animated 8-bit desktop theme plus a CRT TV usage pane. The entry point is `hooks/register.tsx`, which `hooks/hooks.json` loads.

## Commands

- Test: `claude plugin test .`
- Validate: `claude plugin validate .`
- Run locally: `claude --plugin-dir .`

## Rules

- Never edit `hooks/make-colors.js` or `hooks/make-colors.d.ts`. They are generated by Claude Code's mod tooling, must stay exactly as supplied, and are not covered by the MIT license.
- `.claude-plugin/types/` is local tooling output and is gitignored. Don't hand-edit or commit it.
- Keep CPU low. All motion is CSS animation with `steps()` timing on a shared beat: no smooth tweens, no `requestAnimationFrame`, no JS timers driving animation, and nothing animating offstage. Avoid adding animated pieces; the backdrop was cut from about 32 to 18 on purpose.
- The pane must never scroll. `hooks/layout.ts` decides what fits: the quest log shrinks first and then drops out, then the chart drops out, and on a very short window the TV shrinks. Anything new in the pane needs a place in that order and a case in `tests/layout.test.ts`.
- The theme draws only on desktop and mobile surfaces. Terminals get the pane as text (see `drawsThemes` / `opensUnasked` in `layout.ts`).

## Releases

Changes go through a branch and a PR to `main`. A release bumps `version` in `.claude-plugin/plugin.json`, and the commit title ends with the version, for example `Quiet the theme log (0.4.2)`. Update the README when user-visible behavior changes.
